Wake Me Up — project handoff
==========================================

Files in this folder:
1. MASTER_PRODUCT_SPEC.md — full product vision, architecture, privacy, constraints, risks, and development stages.
2. MVP_PLAN.md — staged MVP, acceptance tests, and go/no-go decision.

Start in the new ChatGPT account by uploading this ZIP (or both Markdown files) and asking:
“Read both files. Treat MASTER_PRODUCT_SPEC.md as the long-term product specification and MVP_PLAN.md as the immediate execution plan. Do not start coding until you explain the first technical step and what information you need about my Android phone and laptop. Keep the project free, local-first, and beginner-friendly.”

Important technical caution:
The key assumption to test first is whether the installed Google Maps version exposes a usable public-transport stop count through Android notifications. The project must verify this experimentally before promising that an alarm will work.
